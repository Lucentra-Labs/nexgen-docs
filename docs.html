API Reference

Build secure, observable AI workflows with a clean API surface.

Use the NexGen AI API to trigger workflows, inspect run history, route approvals, and manage agent-backed automations. This page gives you the high-signal version: how auth works, the core resources, and realistic request examples.

Authentication Workflows Runs Approvals Code example

Authentication

Every request must include a bearer token. For production use, issue environment-scoped API keys and rotate them on a regular schedule. Tokens should never be embedded in frontend code. 

Authorization: Bearer <your-api-key>
Content-Type: application/json
Base URL
https://api.nexgenai.example/v1
Format
JSON request and response bodies
Versioning
Path-based versioning for stable upgrades
POST /workflows

Create a workflow

Define an automation that coordinates triggers, agent logic, and optional approval checkpoints.

FieldTypeDescription
namestringHuman-readable workflow name.
triggerobjectEvent or schedule that starts the workflow.
stepsarrayOrdered actions, prompts, and policies.
approvalPolicyobjectOptional rules for gating execution before side effects.
 
{
  "name": "customer-escalation-triage",
  "trigger": {
    "type": "webhook",
    "event": "ticket.created"
  },
  "steps": [
    { "type": "classify", "model": "nexgen-router" },
    { "type": "enrich", "source": "crm" },
    { "type": "notify", "channel": "slack" }
  ],
  "approvalPolicy": {
    "required": true,
    "whenRiskLevelAtLeast": "medium"
  }
}
GET /runs/{runId}

Inspect a workflow run

Run resources give you status, timestamps, output artifacts, and audit metadata for every execution.

StatusMeaning
queuedThe run is accepted and waiting for execution capacity.
runningThe workflow is actively processing one or more steps.
awaiting_approvalExecution paused until a human decision is recorded.
succeeded / failedFinal state with result payloads and logs.
 
{
  "id": "run_92f4",
  "status": "awaiting_approval",
  "workflowId": "wf_18ab",
  "startedAt": "2026-03-15T12:43:09Z",
  "currentStep": "notify_finance",
  "riskLevel": "medium"
}
POST /approvals/{approvalId}/decision

Record an approval

Approval APIs make human oversight explicit. Teams can build audit-friendly workflows where every important side effect is captured with actor identity, reasoning, and timestamped decisions. 

{
  "decision": "approved",
  "comment": "Customer impact confirmed. Proceed with policy-compliant action.",
  "decidedBy": "ops_lead@example.com"
}

JavaScript example

Use this pattern to create a workflow and immediately capture the returned identifier for later inspection.

const response = await fetch("https://api.nexgenai.example/v1/workflows", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.NEXGEN_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    name: "invoice-approval-routing",
    trigger: { type: "schedule", cron: "0 */2 * * *" },
    steps: [
      { type: "extract", source: "inbox" },
      { type: "classify", model: "nexgen-router" },
      { type: "approve", requiredRole: "finance-manager" }
    ]
  })
});

const workflow = await response.json();
console.log("Created workflow:", workflow.id);
